# AFFiNE Research

> Research feeding the Premier Project Hub v2 design / pages / graph build. Focus: what AFFiNE does well and which ideas map onto our **projects ↔ tasks ↔ pages** workflow. Sources are current (2024–2026) and cited inline.

## 1. Overview

AFFiNE (pronounced *[əˈfaɪn]*) is an open-source, local-first knowledge base that markets itself as a single tool replacing **Notion + Miro** (and increasingly Airtable/Monday): "There can be more than Notion and Miro… a next-gen knowledge base that brings planning, sorting and creating all together. Privacy first, open-source, customizable and ready to use" ([GitHub README](https://github.com/toeverything/AFFiNE)). The pitch is "all-in-one workspace" where **docs, whiteboards, and databases are hyper-merged** rather than living in separate apps ([affine.pro](https://affine.pro/)).

Who loves it: privacy-conscious power users, PKM / "second brain" builders, and small teams escaping Notion's cloud lock-in and latency. Reviewers consistently frame it as the rare combo of "a modern interface" plus "owning my data" ([Better Stack](https://betterstack.com/community/guides/linux/affine/)), and PKM writers report migrating off Notion and Obsidian Canvas to it ([XDA — second brain](https://www.xda-developers.com/built-second-brain-with-affine/), [XDA — Obsidian Canvas](https://www.xda-developers.com/open-source-tool-replaced-obsidian-canvas/)). Positioning vs. peers: more visual/canvas-heavy than AppFlowy, more polished and team-oriented than Anytype, and MIT-licensed + self-hostable for free ([AFFiNE vs AppFlowy vs Anytype](https://affine.pro/blog/affine-vs-appflowy-vs-anytype), [pricing](https://affine.pro/pricing)).

## 2. Most-loved features (with why)

- **Edgeless canvas married to docs.** The standout. Users describe it as "like Miro and Notion had a baby" and "a game changer for workflow — you can start with a doc and instantly turn it into a brainstorm map" ([affine.pro — whiteboard](https://affine.pro/blog/interactive-whiteboard-app)). One reviewer literally replaced Obsidian Canvas with it ([XDA](https://www.xda-developers.com/open-source-tool-replaced-obsidian-canvas/)).
- **Local-first speed + real conflict-free collaboration.** Built on CRDTs, so two people editing offline merge cleanly when reconnected — praised as "the gold standard for real-time collaboration" while keeping local speed ([Better Stack](https://betterstack.com/community/guides/linux/affine/)).
- **Data ownership / privacy.** "Privacy is my top priority and AFFiNE delivers. Being able to own my data while having a modern interface is a rare combination" ([Better Stack](https://betterstack.com/community/guides/linux/affine/)).
- **Performance on large docs.** "Handles large documents much better than Notion does in the browser"; self-hosters report no server-render lag even with thousands of blocks ([XDA — never going back](https://www.xda-developers.com/never-going-back-to-notion-after-mastering-open-source-self-hosted-tool/)).
- **Bi-directional links / backlinks.** Auto-created backlinks "significantly lower the cognitive load… of building a densely networked knowledge base," and a Dec 2024 redesign shows reference context inline in the backlinks panel ([Zettelkasten in AFFiNE](https://affine.pro/templates/category-zettelkasten-template), [Dec 2024 update](https://affine.pro/blog/whats-new-affine-dec-update)).
- **Active, responsive maintainers.** Reviewers note "the developers actually listen to feedback. Every update brings meaningful improvements" ([Better Stack](https://betterstack.com/community/guides/linux/affine/)).

## 3. What makes the UX feel good

The core delight is the **doc ↔ edgeless duality**: every document has two views — a structured page view and an infinite "edgeless" canvas — and you toggle between them. You can "drag other documents from my folders straight into a canvas as separate elements, and visually connect them," turning notes into a relationship map without leaving the app ([XDA — Obsidian Canvas](https://www.xda-developers.com/open-source-tool-replaced-obsidian-canvas/)). The editor accepts "both plain text [markdown] syntax and rich text features like bold and italic," so fast typists and WYSIWYG users both feel at home ([XDA — second brain](https://www.xda-developers.com/built-second-brain-with-affine/)).

Because rendering is local rather than round-tripping to a server, interactions like dragging, linking, and reordering blocks feel "faster and smoother" than Notion ([XDA — never going back](https://www.xda-developers.com/never-going-back-to-notion-after-mastering-open-source-self-hosted-tool/)). The edgeless side is described as "practically a mini design suite" with shape tools, pencils, connective arrows, and sticky notes — "the perfect place for visual brainstorming" ([XDA — Obsidian Canvas](https://www.xda-developers.com/open-source-tool-replaced-obsidian-canvas/)). Net effect: low friction, no spinners, trustworthy because it works offline and the data is on your disk.

## 4. Pages / blocks / canvas / graph paradigm

**Everything is a block.** "All files are made up with blocks, and some blocks can be shared and synced in multiple pages" ([affine.pro — pages linking](https://affine.pro/blog/pages-linking-to-pages)). Blocks can be grouped into **databases with multiple views** — kanban, list, timeline, table — the same content rendered differently ([affine.pro — pages linking](https://affine.pro/blog/pages-linking-to-pages)).

**The canvas is a first-class block container, not a separate object.** AFFiNE describes "a true canvas for blocks in any form" where you place "rich text, sticky notes, embedded web pages, multi-view databases, linked pages, shapes and even slides" on one edgeless surface ([GitHub README](https://github.com/toeverything/AFFiNE)). So a database, a doc, and a drawing can all coexist on the same canvas.

**Graph emerges from links.** AFFiNE leans on bi-directional links (`/link` slash command to reference a page/block) and backlinks, plus doc properties/info, to build a connected knowledge web — the Zettelkasten/second-brain pattern ([affine.pro — docs concepts](https://docs.affine.pro/core-concepts/elements-of-affine/docs), [Zettelkasten template](https://affine.pro/templates/category-zettelkasten-template)). (Note: AFFiNE's strength is the *edgeless canvas* as a manual relationship map; it is not primarily an auto-generated force-directed graph like Obsidian's — relevant to our graph build, where we'd be adding the auto-graph AFFiNE leaves to the canvas.)

**Local-first via CRDTs.** The editor framework is **BlockSuite**; the data engine is **OctoBase** (Rust), with **Yjs / y-octo** providing the CRDT layer. OctoBase is "an offline-available, scalable, self-contained collaborative database implemented based on CRDTs… the core to resolve conflicts… so that real-time collaboration and local-first storage is possible," compatible with Yjs and exposing a RESTful API over the block schema ([OctoBase GitHub](https://github.com/toeverything/OctoBase), [OctoBase docs](https://octobase.dev/docs/overview/project_overview)).

## 5. Integration & sync approach

**Workspace is the top-level container.** "All your data is stored locally in your installed path. With work based on Octobase and CRDTs, you can have real-time syncing and collaboration without compromises on data ownership" ([AFFiNE workspaces docs](https://docs.affine.pro/core-concepts/elements-of-affine/workspaces)). Workspaces come in *local* and *cloud-synced* flavors; a cloud workspace "will backup your files and sync them… used to keep all your clients updated with the latest change."

**Self-host = your cloud.** Crucially, when self-hosting, "Enable Cloud Sync" points at *your* server, not AFFiNE's: "it really means your server, and does not mean the Affine servers… you are keeping everything local and self hosted" ([AFFiNE workspaces docs](https://docs.affine.pro/core-concepts/elements-of-affine/workspaces)). Self-hosting is free forever under MIT, via Docker Compose, and you control "Postgres, Redis, storage, email, OAuth, and user management" ([self-host docs](https://docs.affine.pro/self-host-affine/)). One rough edge the community flags: the UI still says "AFFiNE Cloud" on self-hosted instances, which confuses new self-hosters ([issue #7097](https://github.com/toeverything/AFFiNE/issues/7097), [issue #6298](https://github.com/toeverything/AFFiNE/issues/6298)).

**Stack to borrow ideas from:** TypeScript-heavy client (React, Vite, Jotai) + Electron desktop, Rust core (OctoBase/y-octo), Yjs CRDTs ([GitHub README](https://github.com/toeverything/AFFiNE)). The sync model is "edit locally, merge via CRDT, persist to Postgres/object storage on your server."

## 6. Mapping to Premier Project Hub v2

Our stack (React 18 + Vite + TS + Tailwind + shadcn + Supabase + TanStack Query) and our **projects ↔ tasks ↔ pages** model align well with several AFFiNE ideas. Complexity sized for our context (Supabase as the source of truth, not a CRDT engine):

1. **Doc ↔ edgeless toggle on a page (S–M).** Add an "Edgeless/Canvas" view toggle to our block-editor pages, so a project page can flip into a freeform canvas. Start small: read-only/limited canvas (sticky notes, links, arrows) layered over our existing pages. This is AFFiNE's single most-loved idea ([XDA](https://www.xda-developers.com/open-source-tool-replaced-obsidian-canvas/)).
2. **Bi-directional links + backlinks across projects/tasks/pages (M).** A `/link` mention that references any project/task/page and auto-renders a backlinks panel with context. Maps directly onto our entities and feeds the Obsidian-style graph; AFFiNE proves the low-friction value ([Dec 2024 update](https://affine.pro/blog/whats-new-affine-dec-update)).
3. **Linked-page / database blocks (M).** Embed a live, filtered task list or project table *inside* a page as a block with kanban/list/table views — AFFiNE's "blocks grouped as databases with multiple views" ([affine.pro](https://affine.pro/blog/pages-linking-to-pages)). We already have the data in Supabase + TanStack Query; this is mostly UI + query wiring.
4. **Reusable/synced blocks (M–L).** AFFiNE blocks "can be shared and synced in multiple pages" — e.g., one art-request spec block surfaced on its task and its project page, edited once. Requires a block-reference model in our schema.
5. **Local-first responsiveness feel (M).** We can't easily adopt full CRDT sync, but TanStack Query optimistic updates + local cache replicate the "no spinner, instant drag" feel users praise ([XDA — never going back](https://www.xda-developers.com/never-going-back-to-notion-after-mastering-open-source-self-hosted-tool/)). Aim for the *feel*, not the CRDT engine.
6. **Canvas-as-dashboard (L).** AFFiNE's "any block on an edgeless canvas" maps to our editable dashboard goal — drag project cards, task widgets, and embedded views onto a freeform board. Highest effort (layout persistence, drag/resize, embedding live widgets) but the most differentiated; defer until 1–3 land.

**Recommended near-term picks:** items 2 (backlinks/graph), 3 (database blocks), and 5 (responsiveness) — high value, well-bounded, and they directly de-risk our graph and pages build before we attempt the heavier canvas (1, 6) and synced-block (4) work.
